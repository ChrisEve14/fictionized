# Fictionized 📚

A responsive website built as the final project for the Web Development course at Coderhouse.

## 🌐 Live Demo
[https://fictionized.netlify.app/](https://fictionized.netlify.app/)

## 📖 About
Fictionized is a multi-page website designed for a fictional creative writing and storytelling community. It features a polished visual aesthetic and a fully responsive layout built from scratch.

## 🛠️ Built With
- HTML5
- SCSS / CSS3
- JavaScript

## 📁 Project Structure
- `index.html` — Home page
- `about.html` — About page
- `contact.html` — Contact page
- `scss/` — SCSS source files
- `css/` — Compiled CSS
- `images/` — Image assets
- `wireframe/` — Original wireframe designs

## 🚀 Getting Started
1. Clone the repository
   git clone https://github.com/ChrisEve14/fictionized.git
2. Install dependencies
   npm install
3. Compile SCSS
   npm run build-css
4. Open `index.html` in your browser
